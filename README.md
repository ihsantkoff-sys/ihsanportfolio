# Ihsan TK — Portfolio Website

A responsive personal portfolio made with plain HTML and CSS. It is ready to open and edit in Visual Studio Code and publish with GitHub Pages.

## Open it in VS Code

1. Download or copy the `outputs` folder to a place you can find, such as your Desktop.
2. Open Visual Studio Code.
3. Choose **File → Open Folder…** and select the folder containing `index.html` and `style.css`.
4. Open `index.html` to change the text, links, or sections. Open `style.css` to change colors and layout.
5. To preview the page, open `index.html` in a web browser. You can also install the **Live Server** extension in VS Code and select **Go Live** for automatic refresh while editing.

## Add your photo

1. In the same folder as `index.html`, create a folder named `assets` (all lowercase).
2. Copy your photo into it and name the file `ihsan-photo.jpg`.
3. The website will show it automatically. JPG, PNG, and WebP images work; if you use another file name or type, update the image path in `index.html` too.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository**. For a personal site at `https://YOUR-USERNAME.github.io/`, name it `YOUR-USERNAME.github.io`; otherwise any repository name works.
2. In the repository, choose **Add file → Upload files** and upload `index.html`, `style.css`, `README.md`, and the `assets` folder with your photo.
3. Commit the uploaded files to the repository's `main` branch.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait a few minutes and revisit the Pages settings for the published link. For a regular repository, the address will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

When you make edits in VS Code, upload the changed files to the same repository and commit them. GitHub Pages will publish the update.
